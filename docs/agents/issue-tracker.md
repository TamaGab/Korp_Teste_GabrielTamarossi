# Issue tracker: Linear

Issues and specs for this repository live in Linear under the `korp_teste` team.

## Conventions

- Use the available Linear integration to read and manage issues.
- Always scope newly created issues to the `korp_teste` team.
- Prepare issue drafts without publishing them.
- Create issues in Linear only when the user explicitly asks to upload or publish them.
- Do not infer publishing permission from `/to-spec`, `/to-tickets`, or another workflow.
- Preserve Linear issue identifiers in references, comments, and implementation work.

## When a skill says "publish to the issue tracker"

Prepare the issue for publishing, then create it in the `korp_teste` team only after the user explicitly authorizes the upload.

## When a skill says "fetch the relevant ticket"

Retrieve the referenced Linear issue by its identifier, including its description, status, labels, comments, relationships, and blockers when available.
